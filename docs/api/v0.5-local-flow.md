# V0.5 本地主流程 API

本文是前端串接本地主流程的 handoff，目標 API 位址為
`http://localhost:8100`。

## 本地設定

測試建立交易意圖前，先跑 migration 並 seed 標的資料：

```bash
docker compose up -d postgres
make migrate
make seed
make dev
```

seed 內容包含 `2330`、`2317`、`0050`、`00878`。

`LOCAL_MODE=true` 僅供本地開發使用，禁止公開部署。`/dev/*` endpoints
只會在 local mode 註冊。

## 必要 Headers

業務 API 需要 access token：

```http
Authorization: Bearer <accessToken>
Content-Type: application/json
```

交易意圖的 mutating APIs 另外需要：

```http
Idempotency-Key: <uuid-v4>
```

每次新的送出都要產生一個 UUID v4。如果同一筆 request 因 timeout 或網路錯誤
需要 retry，retry 時沿用同一個 key。如果使用者修改 payload 後重新送出，必須
產生新的 key。

缺少 `Idempotency-Key` 會回傳：

```json
{
  "error": {
    "code": "IDEMPOTENCY_KEY_REQUIRED",
    "message": "此操作需要提供 Idempotency-Key",
    "details": {},
    "requestId": "<request-id>"
  }
}
```

同一個 key 搭配不同 payload 重送時，會回 `IDEMPOTENCY_KEY_CONFLICT`。

## 登入

本地 bootstrap admin 由 `.env` 設定：

```text
INITIAL_ADMIN_EMAIL=admin@tingfong.com
INITIAL_ADMIN_PASSWORD=change-me
```

登入：

```bash
curl -i http://localhost:8100/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin@tingfong.com","password":"change-me"}'
```

回應 body：

```json
{
  "accessToken": "<jwt>",
  "tokenType": "Bearer",
  "expiresIn": 900,
  "role": "admin"
}
```

前端將 `accessToken` 存在記憶體中，後續業務 API request 以 Bearer token
送出。

## 建立限價買進意圖

```bash
curl -i http://localhost:8100/trade-intents \
  -H 'Authorization: Bearer <accessToken>' \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "symbol": "2317",
    "quantityLots": 1,
    "strategy": "limit_buy_order",
    "targetPrice": "120",
    "transactionMode": "single_notification",
    "notificationMode": "single"
  }'
```

前端範例：

```ts
const idempotencyKey = crypto.randomUUID();

await fetch("http://localhost:8100/trade-intents", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json",
    "Idempotency-Key": idempotencyKey,
  },
  body: JSON.stringify({
    symbol: "2317",
    quantityLots: 1,
    strategy: "limit_buy_order",
    targetPrice: "120",
    transactionMode: "single_notification",
    notificationMode: "single",
  }),
});
```

成功時 HTTP status 為 `201`。

## 手動評估行情

此 endpoint 僅供 local mode 手動執行 quote evaluation：

```bash
curl -i http://localhost:8100/dev/evaluate-quotes \
  -H 'Authorization: Bearer <accessToken>' \
  -H 'Content-Type: application/json' \
  -d '{"symbols":["2317"]}'
```

## 取消交易意圖

取消也是 mutating API，因此需要一個新的 `Idempotency-Key`：

```bash
curl -i http://localhost:8100/trade-intents/<intent-id>/cancel \
  -H 'Authorization: Bearer <accessToken>' \
  -H "Idempotency-Key: $(uuidgen)" \
  -X POST
```

## 常見錯誤

- `UNAUTHENTICATED`：缺少 Bearer token，或 Bearer token 無效。
- `IDEMPOTENCY_KEY_REQUIRED`：建立或取消時缺少 `Idempotency-Key`。
- `IDEMPOTENCY_KEY_CONFLICT`：同一個 key 被用在不同 payload。
- `UNKNOWN_SYMBOL`：尚未 seed，或 symbol 不在 symbol master。
- `INVALID_TICK_SIZE`：價格不符合市場升降單位。
- `DUPLICATE_INTENT`：已存在等價的有效交易意圖。
- `QUOTE_UNAVAILABLE`：quote provider 尚無該標的即時行情。
- `QUOTE_SUBSCRIPTION_LIMIT_EXCEEDED`：超過 Shioaji demo 訂閱上限。
- `QUOTE_PROVIDER_UNAVAILABLE`：quote provider 暫時不可用。
- `SYMBOL_NOT_AVAILABLE_IN_DEMO`：symbol 不在 Shioaji demo 白名單。
