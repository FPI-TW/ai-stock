# 股票交易機器人時程規劃

## 1. 摘要

- `V0.5`：本地可跑的最小正式垂直切片，不部署。目標是跑通單筆到價提醒主流程，供內部展示與前端串接。
- `V1`：正式上線版，部署於 `EC2 + RDS`，補齊登入、批次、通知、管理後台、正式資料來源、監控與營運安全。

估時：

- 換算人日，以 `1 人日 = 7.5 小時` 估算。
- 工時不包含前端實作、資料供應商合約、生產基礎設施採購、法務審核、產品驗收時間。

## 6. 主要依賴與風險

### 外部依賴

- 正式行情供應商尚未選定，會影響 V1 正式行情來源與行情健康監控。
- 公司行動資料來源需要以交易所與公開資訊觀測站實際格式驗證。
- 前端另開程式庫，V0.5 需要後端先提供本地介面範例，V1 再補完整介面合約。
- EC2 與 RDS 規格、備份策略、網路與機密管理方式會影響上線準備。

### 時程風險

- `BE-V1-05` 正式行情來源若供應商延遲，會影響行情健康、暫停恢復與正式測試。
- `BE-V1-09` 公司行動與除息調整牽涉資料正確性，可能需要額外資料比對時間。
- `BE-V1-10` 批次匯入依賴停利 / 停損、二擇一群組、除息有效價邏輯完成後才能收斂。
- `BE-V1-17` 上線準備需與基礎設施決策同步，不建議等所有功能完成後才開始確認。
