# 工單

本目錄只放「已定案、尚未完成、需要完整設計與驗收條件」的複雜工單。

## 目前工單

## 生命週期

- 小型 bug、enhancement 與單點技術債使用 GitHub Issues，不在本目錄建立副本。
- 工單內容必須符合 `docs/product.md`，並清楚標示尚未實作，不得寫進 current-state 架構或 API。
- 實作完成的同一個 PR 必須更新相關主題文件，接著刪除工單與本索引項目。
- 取消或被新決策取代時直接刪除；不移入 archive、不保留完成清單或白話副本。
- 歷史背景、完成內容與舊方案一律透過 Git history／PR 追溯。
