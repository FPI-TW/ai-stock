# P1 白話說明：停利 / 停損 + OCO 群組

> 這份是 [P1 工單](P1-take-profit-stop-loss-oco.md) 的白話導讀。屬**上線後**迭代。

---

## 一句話

**P1 = 補上「持倉型停利/停損」與「二擇一自動取消（OCO）」這兩種策略。**

---

## 現況與缺口

V0.5 已經有 8 種策略（買賣到價、限價、移動出場、市價、TWAP）。**缺**的是：拿著股票的人想設「漲到 X 賣（停利）」或「跌到 Y 賣（停損）」，以及把這兩個綁成一組「先到哪個就觸發、另一個自動取消」。

---

## P1 做的事（白話）

**1. 停利 / 停損**
針對「手上有持倉」的人：
- 多單（看漲買進）：漲到目標→停利提醒；跌破目標→停損提醒。
- 空單（看跌放空）：跌到目標→停利回補；漲破目標→停損回補。
- 方向由「持倉方向」自動推算，使用者不用自己選買或賣（避免設錯）。

**2. OCO 群組（二擇一）**
把一個停利 + 一個停損綁成一組：
> 哪個先到就觸發哪個，**另一個自動取消**。取消一腳就整組取消，不能只留半組。

**3. 兩種防呆**
- 建立時檢查價格關係合不合理（多單停利價要高於停損價，空單相反）。
- 萬一同一筆行情兩腳同時成立（資料異常）：不亂猜選一邊，整組標成「異常」、發異常通知請使用者重建，並記一筆給管理員查。

**4. 立即觸發**
如果建立當下價格就已經符合條件，直接立即觸發、存當下行情、發通知，不進入長期監控。

---

## P1 的邊界

| 不做 | 原因/交給 |
|---|---|
| 做空進場 | V1 只支援空單的停利/停損回補 |
| 驗證實際持倉 | V1 允許聲明，接券商（V2）才驗 |
| 通知交付保證 | **P2**（上線初期走既有路徑） |
| 漲跌停 / 當日限制檢查 | V1 不做（已延後） |
