# P4 白話說明：除息調整（Corporate Action）

> 這份是 [P4 工單](P4-corporate-action-dividend.md) 的白話導讀。屬**上線後**迭代。

---

## 一句話

**P4 = 配息那天股價會跳，系統自動把你的目標價跟著調，免得提醒算錯。**

---

## 為什麼需要

股票「除息」（發現金股利）那天，股價會自動扣掉股利金額往下跳一段。如果系統還拿你原本設的目標價去比，就會**算錯、誤觸發或漏觸發**。上線初期靠管理員手動避開除息股；P4 把這件事自動化。

> ⚠️ V1 **只處理現金股利**（固定金額扣除）。配股、減資、分割等比例調整不做，碰到就標「不支援」並暫停那檔的提醒。

---

## P4 做的事（白話）

**1. 自動抓除息資料**
從證交所公告抓每天的除權除息事件，整理成內部資料；管理員可以人工覆寫修正。

**2. 盤前算好一份快照**
開盤前先把當天每檔的調整金額算好存成「當日快照」。開盤後策略只看這份快照，盤中有修正不重算已啟用的提醒（避免算到一半變來變去），改為標記異常、影響下一份快照。

**3. 自動調目標價**
> 調整後有效價 = 你輸入的原始價 − 現金股利金額。
原始價保留不覆蓋；調整後若不是合法跳動單位，往「比較難觸發」那邊取整（避免讓條件更容易成立）。通知會同時顯示原始價、股利金額、調整後價。

**4. 資料有爭議就暫停**
如果某檔的除息資料有疑慮或是不支援的類型，把相關提醒**暫停**並通知使用者，不亂觸發。管理員可人工覆寫修正（要留紀錄）。

---

## 對齊 domain-spec 的範圍

| P4 做的事 | 對齊 spec 出處 |
|---|---|
| 調整公式 + 保留欄位 + round away from trigger | **§9** lines 452–468 |
| 除息通知顯示三欄（原始價／股利金額／調整後價） | **§12** lines 652–657 |
| Provider adapter + importer + import report | **§9** lines 470–497 |
| 盤前 snapshot、盤中不重算 | **§9** lines 497–504 |
| unsupported action → 暫停 | **§9** lines 493–495 |
| 資料來源（TWSE/TPEx + MOPS authority check） | **§24** lines 1205–1210 |

> 註：除息通知顯示三欄屬**通知章節（§12）**，實作上通知 payload 串接跨 P4（產生調整資料）與通知票（P2/既有 trigger payload）；P4 負責提供原始/股利/調整後三個值，由通知側 render。

**一句話**：P4 切自 spec **§9（除息調整）+ §24（corporate action 資料來源）**。

---

## P4 的邊界

| 不做 | 原因/交給 |
|---|---|
| 配股 / 減資 / 分割等比例調整 | 標 unsupported，V1 不做 |
| 漲跌停 / invalid_for_day | V1 不做（已延後） |
| admin 覆寫介面 | **P5**（P4 提供覆寫指令 + 紀錄） |

---

## 做完 P4 之後

除息日的提醒會自動用調整後的有效價，不再算錯，管理員不用再手動避開除息股。
