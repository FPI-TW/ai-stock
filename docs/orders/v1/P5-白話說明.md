# P5 白話說明：Admin 監控 + 資料覆寫 + Kill Switch（完整版）

> 這份是 [P5 工單](P5-admin-monitoring-overrides-killswitch.md) 的白話導讀。屬**上線後**迭代。

---

## 一句話

**P5 = 把管理後台補完整：監控畫面、告警、可分層的緊急停止、改資料、調設定。**

---

## 現況與缺口

上線時管理員只有「開帳號 / 停用帳號」（L1）和「全部喊停那一顆鈕」（L2）。P5 把管理後台補成完整版：看得到系統健康、出問題會告警、能精準地停某一塊、能修資料、能線上調參數。

---

## P5 做的事（白話）

**1. 監控儀表板**
管理員看得到整體狀況：有多少提醒、多少失敗、影響哪些股票。**預設只看統計數字**；要看某個使用者的完整內容，必須走「客服查閱」流程、輸入原因、留紀錄（保護隱私）。

**2. 自動告警**
系統異常會主動通報管理員：行情斷線、某檔行情連續異常、Telegram 失敗率太高、除息匯入失敗、開盤前快照沒產出、待辦塞車、盯價程式心跳停了。

**3. 分層緊急停止（把 L2 那顆鈕補成 5 層）**
除了「全部喊停」，再加上：只停某一檔、只停 Telegram、只停所有外部通知（保留站內）、只停除息調整。出小狀況時可以精準處理，不用全部停掉。

**4. 改資料（覆寫）**
管理員可以覆寫股票狀態、覆寫除息資料（修正抓錯的）。每次都留紀錄。

**5. 線上調參數**
把「一個人最多建幾筆」這類上限，從寫死的設定改成管理員能線上調整。

## 對齊 domain-spec 的範圍

| P5 做的事 | 對齊 spec 出處 |
|---|---|
| 監控 dashboard（aggregate）+ 查使用者內容需 reason+audit | **§13** line 690、**§18** lines 1074–1075 |
| 7 類最低告警 | **§18** lines 1076–1084 |
| Kill switch 分層（5 層，繼承 L2 全域層擴充） | **§18** lines 1086–1098 |
| symbol / corporate action 覆寫 | **§13** lines 771–773、**§9** override |
| platform_config 可調（限額等） | **§15** line 861 |

**一句話**：P5 切自 spec **§13（admin 能力）+ §18（監控與 kill switch）+ §9（admin 覆寫）+ §15（可調上限）**。
