注意事項 · 操作檢查清單

追過的雷區與正確操作方式

注意
  • 盤外建立 → scheduled 卡住 V0.5 沒有 next-day activation job。Demo 前先到服務端凍結時鐘到 09:30 再建單。
  • 「推送 → 建單」也會觸發 建單流程有 inline trigger，會讀 provider 既存快照。雙向都不需手動評估。
  • 推送回應沒有 triggered IDs /dev/push-quote 是 fire-and-forget；前端跨 4 個 user 查 /notifications 聚合。
  • Side 必須對到策略 buy=ask、sell=bid。last 不驅動任何策略，僅供觀察。
  • 0 觸發的智慧診斷 盤外提示 demo 流程；盤中 side 錯就建議改側別；side 對但價未到就列條件與 owner。
  • Owner 隔離 dispatcher 跑所有 user 的 active 委託，但 /notifications、/trade-intents 都 X-Local-User-Id 鎖在當前身分。
  • 手動觸發評估幾乎冗餘 in-memory demo 用不到；保留是給真實 broker provider 或 debug 用的後門。
